# First Shutter

Ryo Yoshioka (吉岡 涼) の写真撮影業ブランドサイト。

- Web: https://frist-shutter.com/ (移行後)
- Instagram: [@roythemoon](https://instagram.com/roythemoon)
- 運営: [Up the Moon合同会社](https://upthemoon.co.jp/)

## 概要

- ポートレート / 風景 / 都市 / 委託撮影
- 受賞: Tokyo International Foto Awards / Int'l photography awards / 日本広告写真協会 各賞入選
- 掲載: int'l photography awards22 / プロカメラマンファイル 2024 / 年鑑日本の広告写真 2025
- 資格: 一等無人航空機操縦士 (2025 年取得)

## 構成

- `index.html` — Home
- `portfolio.html` — Portfolio (6 カテゴリ: All / Selected / Landscape / Portrait / City / Commission)
- `about.html` — About (代表挨拶・受賞歴・サービス)
- `contact.html` — Contact (Formspree 連携)
- `assets/` — CSS / JS / 画像
